# Student Dataset Management System

## Description
A beginner-friendly Python project that uses NumPy to create and manage a structured dataset of 20 students.

## Features
- Create a dataset containing 20 students.
- Store Student ID, Age, Math, Science, English and AI marks.
- Display NumPy array properties:
  - Shape
  - Dimensions
  - Size
  - Data Type
- Compare Python Lists and NumPy Arrays.
- Convert a 2D dataset into a 3D array representing two classrooms.

## Technologies Used
- Python
- NumPy

## Concepts Learned
- NumPy arrays
- 2D and 3D arrays
- Array properties
- Array reshaping
- Numerical operations

## How to Run

1. Install NumPy:
   `pip install numpy`

2. Run the program:
   `python main.py`
